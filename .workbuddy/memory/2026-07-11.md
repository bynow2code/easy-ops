## EasyOps Windows 闪退修复（根因定位 + 代码加固）

### 问题
Windows 11 安装后打开即闪退，用户无任何错误提示。

### 根因（3 层叠加）
1. **`package.json` 的 `build.files` 含 `!node_modules/**/*`** → electron-builder 打包时把 `app.asar` 里的生产依赖（electron-updater）也排除了 → `require('electron-updater')` 抛错 → 被 catch 后静默 `app.quit()`
2. **CI (`release.yml`) 缺少 server 依赖安装步骤** → 只装了根目录和 client/ 的依赖，从未执行 `cd server && npm ci` → CI 上 `server/node_modules` 不存在 → 打包进安装包的是空壳 → 运行时报 `Cannot find module 'express'`
3. **`extraResources` filter 未显式包含 node_modules** → 即使有依赖也可能被 glob 默认排除

### 修复内容
- **`package.json`**: 去掉 `build.files` 中的 `!node_modules/**/*`；server extraResources filter 加 `node_modules/**/*`
- **`release.yml`**: Windows 和 macOS 作业均新增「步骤5.5: 安装后端依赖」(`cd server && npm ci`)
- **`server/index.js`**: port.txt 写入路径从 `__dirname`(只读) 改为系统临时目录；`app.listen` 加 `.on('error')` 捕获
- **`electron/main.js`**: 全面加固——未捕获异常弹窗、渲染进程崩溃处理、页面加载失败提示、后端 stderr 记录到 main.log 并弹窗、重复实例检测弹窗、electron-updater 缺失时降级不崩溃
- **`server/package-lock.json`**: 确认已被 git 跟踪（CI npm ci 前提）
