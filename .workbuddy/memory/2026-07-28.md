## README 增加 SSH 首次连接提示
- 用户在 README「常见问题」中新增一条：脚本 SSH 连远程服务器首次执行会卡住 / host key 错误。
- 原因：首连新主机会交互式询问是否信任并把指纹加入 known_hosts，而应用内脚本执行是非交互式的，无法应答。
- 文档建议：先用系统自带终端（macOS/Linux Terminal、Windows Git Bash/WSL）手动 `ssh user@host` 连一次、输入 yes 把指纹写入 known_hosts；服务器重装导致 fingerprint 变更时先 `ssh-keygen -R host` 再手动重连。

## 新增功能：界面主题切换（跟随系统 / 浅色 / 深色）
- 需求：增加软件界面风格切换，默认跟随系统，切换图标放在 App Info 左侧。
- 实现：
  - CSS：`client/src/App.css` 用一次性 Node 脚本把中性色板（背景/文字/边框）转成 CSS 变量（--bg / --bg-surface / --bg-subtle / --bg-hover / --border / --border-strong / --text / --text-secondary / --text-muted）。`:root`(默认浅色) / `:root[data-theme="light"]` 用浅色值；`:root[data-theme="dark"]` 与 `@media (prefers-color-scheme: dark) :root[data-theme="system"]` 用深色值。彩色语义色（primary/成功/警告/危险及 tints）保持字面量，深浅色均可读。
  - 关键细节：`#fff` 仅当其为 background 值时转 `var(--bg-surface)`，保留 `color:#fff`（彩色按钮白字）；`background-color: white` 关键字（4 处）也转 `var(--bg-surface)`；App.jsx 内两处内联 `color:'#666'` → `var(--text-secondary)`。
  - JS：`App.jsx` 新增 `theme` state（localStorage 'easyops-theme'，默认 'system'）+ `cycleTheme` 循环 system→light→dark；`useEffect` 把 `data-theme` 写到 `<html>`。`index.html` 加内联脚本在 React 加载前应用主题防闪烁。
  - 工具栏：在「检查更新」与「App Info」之间插入主题图标按钮，图标随状态变（太阳=浅色 / 月亮=深色 / 显示器=跟随系统），title 显示当前模式。
  - README 核心功能表新增「🌗 主题切换」一行。
- 验证：esbuild 转译 App.jsx 通过（exit 0）；App.css 花括号平衡（255/255）；`grep` 确认中性字面量仅剩变量定义本身、#fff 背景已转、白字保留。
- 注：无法在本环境可视化验证；彩色 tints 在深色下为浅色小色块（如成功/危险的浅底 badge），属已知可接受范围，后续可按需把 tints 也变量化。

## 增加程序最小宽度，修复窗口缩窄时脚本列表列文字竖排
- 需求：用户截图显示窗口缩到最小时，脚本列表 Name 列被压到文字竖着排列（每字母一行），PMS 状态等也竖排。
- 根因：当前 `minWidth: 960`，左侧面板占 45% 只剩约 432px；脚本表格是 `table-layout: fixed`，固定列（复选框 40px + Status 80px + Actions 240px）占 360px，Name 列 35% 被严重压缩。
- 实现：
  - `electron/main.js`：`minWidth` 由 `960` 提高到 `1280`。
  - `client/src/App.css`：Name 列（`th/td:nth-child(3)`）新增 `min-width: 140px` 兜底，即使窗口被压到接近最小宽度，表头 "Name" 也不会再竖排。
- 验证：`node --check electron/main.js` 通过；esbuild 转译 `client/src/App.jsx`（含 CSS import）通过。
