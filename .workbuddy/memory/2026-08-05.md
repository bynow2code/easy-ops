## 对齐 xterm 终端视觉样式至 VS Code 默认

- 用户反馈 xterm 终端仍显"极简风"、不像 VS Code 集成终端。
- 修改：
  - `client/src/components/ExecutionCard.jsx`：xterm 配置对齐 VS Code 默认——`fontSize: 14`、`fontFamily: 'Consolas, "Cascadia Code", "Courier New", monospace'`、`cursorStyle: 'line'`、`cursorBlink: true`、`lineHeight: 1.2`。
  - `client/src/styles.css`：`.exec-card__term` 内边距由 `8px 0` 改为 `8px`（左右增加 8px 留白，模拟 VS Code 终端内边距）；host 保持 100% 填满内容区，FitAddon 计算行高不受影响。
- 验证：独立 xterm 预览页通过 Vite dev server 渲染并截图 `outputs/xterm-vscode-style.png`，确认彩色 PS1、Consolas 14px 字体、8px 四周留白均生效，布局无裁切。
- 质量门禁：`npx eslint client/src/components/ExecutionCard.jsx` 通过。

## 将 xterm 恢复为最原始默认样式

- 用户再次反馈希望使用"xterm 最原始的样子"，不要 VS Code 风格。
- 修改：
  - `client/src/components/ExecutionCard.jsx`：删除 `XTERM_THEME` 常量、`readDomTheme` 函数与主题跟随 effect；`new Terminal({})` 使用空配置，恢复默认字体、默认字号、默认方块光标、默认黑底白字主题。
  - `client/src/styles.css`：`.exec-card__term` 去掉 padding 与背景色覆盖，移除滚动条自定义颜色，恢复 xterm 原生填满布局。
- 验证：独立 xterm 预览页截图 `outputs/xterm-raw-style.png`，确认黑底白字、默认字体、方块光标、无 padding 的原始外观。
- 质量门禁：`npx eslint client/src/components/ExecutionCard.jsx` 通过。

## 将 xterm 改为 Git Bash / mintty 风格

- 用户反馈希望使用"Git Bash 那种花花绿绿"的终端外观。
- 修改：
  - `client/src/components/ExecutionCard.jsx`：新增 `GITBASH_THEME`（mintty 鲜艳 16 色 ANSI + 黑底 #000000 / 浅灰前景 #bfbfbf）；`new Terminal({...})` 配置 `fontFamily: Consolas...`、`fontSize: 14`、`lineHeight: 1.2`、`cursorBlink: true`、`theme: GITBASH_THEME`。
  - `electron/pty-host.js`：bash 启动 init 文件在 `source ~/.bashrc` 前增加 `source /etc/profile`，从而加载 Git Bash `/etc/profile.d/` 下的彩色 PS1（`__git_ps1`）、`ls --color=auto` alias 与完整环境。
- 验证：独立 xterm 预览页截图 `outputs/xterm-gitbash-style.png`，确认绿色 user@host、蓝色路径、彩色 ls（蓝目录/绿可执行/青链接）、黄色 git 分支、绿色 git 状态文本均正确渲染。
- 质量门禁：`npx eslint electron/pty-host.js client/src/components/ExecutionCard.jsx` 通过。
