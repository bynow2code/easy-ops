### 改动点
1. **client/src/App.jsx（最大收益）**
   - 抽出三个辅助，统一「后端优先、失败回退 localStorage」写法：
     - `applyRepo(repo)`：按字段是否存在回填 scripts/groups/defaultGroup（避免后端只回部分字段时把其余状态清零）。
     - `persistWithFallback(apiCall, transform, apply)`：成功→apply(repo)；失败→在前端 localStorage 复刻同一变换（transform 与 server 纯函数同源）并回写再 apply。
     - `persistLocal(mutate)`：仅把变更写前端 localStorage（脚本级乐观更新落盘）。
   - 路由：`loadScripts`、`handleConfirmDeleteGroup`、`handleImport` 用 `applyRepo`；`handleConfirmRenameGroup` 用「只动 groups+defaultGroup」的 apply 回调（不影响 scripts，保持等价）；`handleSaveScript`/`handleMoveScript`/`handleRemove`/`handleSaveGroup` catch 走 `persistLocal`。
   - 关键等价性保护：`applyRepo` 按字段存在与否回填，故后端只回 `{ok,groups}` 的 addGroup 不会误清空 scripts；rename 的 apply 回调不碰 scripts，避免回退路径把未落盘的乐观脚本新增冲掉（原逻辑亦然）。
   - 命名：`reloadShells` 内 `st`→`shellState`、`fe`→`localShells`。
   - 因 `loadScripts` 现闭包引用 `applyRepo`，用 `useCallback` 把 `applyRepo`/`reloadShells`/`loadScripts` 稳定化，挂载 effect 依赖改为 `[reloadShells, loadScripts]`，消除 `react-hooks/exhaustive-deps` 警告（仍只跑一次，等价）。
2. **electron/pty-host.js**：删除无人引用的死导出 `getSessionIdForExec`；`write/resize/killByExec/killAll` 内 `s`→`session`（可读性）。
3. **server/shell-detect.js**：`classifyPosix` 三段 if 合并为 `return !/cmd\.exe$/i.test(p) && !/powershell/i.test(p);`（等价）。
4. **server/shell-routes.js**：局部函数 `ud`→`userDataDir`（12 处引用 rename）。
