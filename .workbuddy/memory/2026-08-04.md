## 修复：xterm 终端输出多行垃圾（命令回显 + 哨兵语法错误 + 多余 PS1）
- 用户反馈：单行脚本（如 `echo hello`）在 xterm 里输出一堆"多余的东西"，不该是多行形式。
- 实测（node-pty 直连真实 WSL bash，`echo hello` 跑过真实 `sentinelFilter` 剥 ANSI）：
  旧交互式 shell 可见文本为：`$ echo hello`（命令被回显） / `hello`（输出） / `$ `（脚本后 PS1） / `$ `（哨兵后 PS1）。
  根因：
  1) 交互式 shell 必然回显脚本命令、打印 PS1；
  2) 旧哨兵 `\x1b[2K\r\x1b[2K; echo TOKEN` 里的 `\r` 在 bash 输入态被当回车，把 `; echo TOKEN`
     拆成独立命令 → `-bash: syntax error near unexpected token ';'`（靠 consumeLines 侥幸吞掉，脆弱）。
- 方案（保留可交互终端，按用户选择）：bash 家族启动即用 `--init-file` 关回显 + 极简提示符，
  哨兵并入脚本末尾同一行恢复回显。非 bash（zsh/fish）沿用旧哨兵方案。
- 改动 `electron/pty-host.js`：
  - 新增 `isBashFamily()` / `ensureBashInitFile()`（写 `<userData>/easyops-shell-init.sh`：`stty -echo` + `PS1='$ '`）/ `toBashInitPath()`（Windows→bash 路径：Git `/d/…`、WSL `/mnt/d/…`）。
  - `openSession`：bash 家族 `spawnArgs = ['--init-file', initBash]`（wsl.exe 启动器则前缀 `bash`）；
    注入 `content.replace(/\s+$/,'') + '; echo "<TOKEN>"; stty echo\n'`（哨兵与恢复回显并入末尾，只留一个 PS1）；
    无脚本时补 `stty echo` 恢复回显。非 bash 仍写独立 `doneMarker`。
- 验证（端到端，直接用真实 `openSession` + 真实 `filterSentinelChunk`）：`echo hello` 过滤后可见文本仅
  `$ `（启动提示符）/ `hello`（真实输出）/ `$ `（跑完可交互提示符）——无命令回显、无语法错误、无多余 PS1，TOKEN 无泄漏。
  `npx eslint electron/pty-host.js` 通过。

## 修复：xterm 多行脚本输出前出现 PS2 空行
- 用户截图：mns_pms 脚本输出前出现大量 bash `>` 空行（PS2 continuation prompt），不像正常终端。
- 根因：上一轮把多行脚本内容直接 write 进交互式 bash，bash 每读完一行不完整命令都会打印 PS2 `>`，
  即使 `stty -echo` 关了命令回显，bash 自己打印的提示符仍会出现。
- 方案：bash 家族不再直接 write 多行 content，而是先写入 `<userData>/easyops-script-<execId>.sh`，
  再向 PTY 发送单行 `source "<bashPath>"; echo "<TOKEN>"; stty echo\n`。
  - `source` 让脚本在当前 shell 执行，保留"跑完可继续交互"能力；
  - 单行命令不触发 PS2，彻底消除输出前的 `>` 空行；
  - `stty -echo` 已关回显，所以 `source ...` 命令本身也不显示；
  - 会话结束 `term.onExit` 中删除临时脚本文件。
- 改动 `electron/pty-host.js`：
  - 新增 `ensureScriptFile()`（写临时脚本文件并返回 bash 路径）与 `removeScriptFile()`（清理）。
  - 修改 `openSession` bash 分支：有脚本时写临时文件并 source；无脚本时直接 `echo TOKEN; stty echo`。
  - 顶部执行模型注释同步更新。
- 验证（node-pty 仿真 + 真实 `openSession` + 真实 `filterSentinelChunk`）：
  - 仿真：mns_pms 多行脚本过滤后可见文本仅 `$ ` / 4 行脚本输出 / `$ `，无 PS2 空行、无命令回显。
  - 真实 `openSession`：结果一致，TOKEN 无泄漏。
  - `npx eslint electron/pty-host.js` 通过。
- 同步更新 `.workbuddy/memory/MEMORY.md`。
